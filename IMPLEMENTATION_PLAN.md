# Implementation Plan

LedgerProof is an independent financial-audit product that reuses the CyberGuard controlled response executor at runtime. The detailed active plan is maintained in `task_plan.md`.

## Milestones

1. CyberGuard GHCR governance adapter.
2. Seven financial audit Agents and deterministic evidence tools.
3. Ant Design audit command center.
4. Docker Compose integration and scenario smoke test.
5. Public documentation and handoff.

Architecture decisions live in `docs/adr/`.
